# Responsive Web Design Internship Project

A beginner-friendly responsive webpage built using HTML5 and CSS3.

## Files
- `index.html` — webpage structure and content
- `style.css` — colours, layout, typography, and responsive media queries

## How to view
Open `index.html` in a web browser. The stylesheet is linked from the HTML file.

## Responsive features
- Flexible grid layouts
- CSS media queries for tablet and mobile widths
- Navigation that wraps on smaller screens
- Responsive text sizes and content spacing

This is a sample frontend project for learning and demonstration. Update the design as needed to match the exact wireframe supplied by your internship.
